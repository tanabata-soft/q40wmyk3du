# 8cmシングル ジャケット・デザイン調査

実物の8cmシングル（短冊）ジャケット写真を年代別・ジャンル別に調べた記録。デジタルシングルCDの表絵を作るときの「型」として使う。
調査: 2026-11-16、Web上のジャケット写真・資料で確認したサンプル **165点**。年代別内訳: 1988年 14点 / 1989年 15点 / 1990年 11点 / 1991年 20点 / 1992年 9点 / 1993年 15点 / 1994年 15点 / 1995年 11点 / 1996年 14点 / 1997年 13点 / 1998年 18点 / 1999年 10点（時代区分では 1988–1991年 60点 / 1992–1995年 50点 / 1996–1999年 55点）。ジャンル別内訳: アイドル 28点 / ポップス系 51点 / ロック系 56点 / 演歌・歌謡 14点 / アニソン 16点。
サンプル台帳（1点ごとのデザイン読み・出典URL・割り当てた型）は `docs/research/single-samples.md` に、参照画像は `docs/research/img/` に保存（いずれもこのリポジトリ内）。
これは 2026-11-04 の前回調査（実物 約20点、型A〜C）の全面改訂である。前回調査の台帳と参照写真はリポジトリ外の作業フォルダだけに置いて失われたため、今回は台帳・画像ともリポジトリ内に保存する方針に変えた。型の再編にあたっては、既存の制作実績との対応を壊していない（旧型→新型の対応は末尾の対応表を参照）。
薄いセル: 演歌・歌謡×1997年以降は **0点でサンプル不足・要追加調査**（演歌のサンプルは1996年まで）。アニソン×1988年・1990年も 0点で薄い。型D（演歌・歌謡様式）の1990年代後半の姿は、追加調査までは1996年以前の様式からの推定として扱うこと。

## 型の一覧

### 型A: 帯＋ポートレート型（1988–1991の商品型）

- 年代・ジャンル適性: 1988–1991年のアイドル/歌謡/ポップスが本拠。バンドでも初期はこの文法が標準だった（B'z初期、ZARDのデビュー作）。1998年のモーニング娘。『モーニングコーヒー』のように、アイドルでは後年まで残る様式。
- 構図: ポートレート写真が主役。写真＋色帯・白帯・色パネルの二段構成が定番で、上端にレーベル帯を通す例も多い。写真の領域と文字の領域がはっきり分かれる。
- タイポグラフィ: タイトルは大きい。筆文字・極太ゴシック・スクリプト体など、書体そのものがデザインになる。アーティスト名の筆記体ロゴも様式の一部。
- 色彩: レーベル色やビビッドな原色の帯。写真の色と帯の色の対比で画面を作る。
- 帯・クレジットの扱い: 価格・品番・℗・カップリング名などのクレジット小字が表面に載る（商品記号が表に出ている）。タイアップ表記も表面に置かれる。
- 画像の題材方向: スタジオポートレート。衣装の色と背景色の組み合わせで画面を作る。
- 具体例（裏付け44点）: 田原俊彦『抱きしめてTONIGHT』(1988)、浅香唯『C-Girl』(1988)、光GENJI『パラダイス銀河』(1988)、工藤静香『嵐の素顔』(1989)、中森明菜『LIAR』(1989)、B'z『BE THERE』(1990)、ZARD『Good-bye My Loneliness』(1991)。

### 型B: タイポグラフィ勝負型（1992–1995の設計型）

- 年代・ジャンル適性: 1992–1995年のポップス/ロック全般が本拠。ビーイング系（WANDS、DEEN、FIELD OF VIEW、大黒摩季ら）の「暗い写真＋金色セリフ体＋縦書きタイトル」の整った様式もこの型の分派。1996年以降もダンス系・アイドル系に残存した（安室奈美恵『CAN YOU CELEBRATE?』(1997)、モーニング娘。『LOVEマシーン』(1999) はこの型に割り当てた）。
- 構図: 写真と文字が同じ重さで設計される。左右・上下・斜めの分割構図、色面で写真を挟む三段構成、写真の上に文字を大胆に重ねるレイヤー構成。
- タイポグラフィ: 巨大な漢字・数字（シャ乱Q『18ヶ月』）、斜め組み、縦に積む、字間を空けるなど、実験の幅が型Aより広い。タイトルが画面の主役になる例が増える。
- 色彩: 色面の大きな分割と原色の対比。モノクロ寄りの写真＋金文字も定番。
- 帯・クレジットの扱い: 表面のクレジット小字は減り始め、タイアップなどの情報は丸いタイアップシール（ステッカー）が担うようになる。カップリング表記は小字で表面に残る。
- 画像の題材方向: バンドの集合写真、顔のアップ、俯瞰やコラージュなどの仕掛け写真。
- 具体例（裏付け47点）: シャ乱Q『18ヶ月』(1992)、森高千里『私がオバさんになっても』(1992)、WANDS『時の扉』(1993)、B'z『裸足の女神』(1993)、大黒摩季『あなただけ見つめてる』(1993)、篠原涼子『恋しさと せつなさと 心強さと』(1994)、スピッツ『ロビンソン』(1995)。

### 型C: ファッション写真型（1996–1999の静かな型）

- 年代・ジャンル適性: 1996–1999年のポップスが本拠。ロックでも静かな作例はこの文法に寄る（GLAY後期、L'Arc〜en〜Ciel）。先行例として L'Arc〜en〜Ciel『Blurry Eyes』(1994) をこの型に割り当てた。
- 構図: 顔のクローズアップやファッション誌的なポートレートが全面を占め、写真表現そのものがデザインになる（ミラー構図、横向き配置、前景の小道具）。写真を小さく置いて余白で静けさを作る使い方もロック側にある（GLAY『誘惑』『SOUL LOVE』）。
- タイポグラフィ: 小さく静かに。細いローマ字、字間を広げた表記、縦組み、端に寄せた配置。アーティスト名は小文字ローマ字で隅に置く。タイトル文字が顔の上に落ちる例（浜崎あゆみ『Trust』の縦の赤文字）でも、文字は写真に従属する。
- 色彩: 彩度を落としたトーン、モノクロ、白基調が多い。
- 帯・クレジットの扱い: レーベル帯も表面クレジットも姿を消し、情報は裏面へ回る。表面に残るのはタイアップシール程度。
- 画像の題材方向: ファッション撮影、コンセプトポートレート。
- 具体例（裏付け25点）: 浜崎あゆみ『poker face』(1998)、浜崎あゆみ『Trust』(1998)、浜崎あゆみ『TO BE』(1999)、安室奈美恵『How to be a Girl』(1997)、宇多田ヒカル『Automatic / time will tell』(1998)、L'Arc〜en〜Ciel『HONEY』(1998)、GLAY『Winter, again』(1999)。

### 型D: 演歌・歌謡様式型（全年代の不変様式）

- 年代・ジャンル適性: 演歌・歌謡の全年代。様式がほぼ不変で、時代の型（A〜C）の流行の影響を受けない。アルバム調査の型F（演歌・歌謡様式）と同じ構図が、短冊判型でも確認できた。ただし本調査の演歌サンプルは1996年までで、1997年以降はサンプル不足・要追加調査。
- 構図: 着物（女性）または礼装・スーツ（男性）のポートレートが中心。背景は無地グラデーションか、曲の情景を薄く重ねる。上下2分割で下段を色帯にする例もある（細川たかし『応援歌、いきます』、天童よしみ『珍島物語』）。
- タイポグラフィ: タイトルは縦書きの筆文字/明朝で最大級、白・金・赤のいずれか。歌手名も縦書きで大きく添える。横書きに転じた例（長山洋子『倖せにしてね』(1996)）でも、階層（タイトルと歌手名の大きさ）は崩れない。
- 色彩: 金・赤・紺・紫など「重み」のある色。暗めの地に顔と文字を浮かせる。
- 帯・クレジットの扱い: 品番・価格・CD SINGLEロゴ・レーベルロゴが下部に集まる。作詞・作曲・編曲のクレジットまで表面の端に載る例もあり（坂本冬美『夜桜お七』）、情報密度の高さ自体が様式。
- 画像の題材方向: スタジオポートレートが原則。
- 具体例（裏付け14点）: 香西かおり『雨酒場』(1988)、美空ひばり『川の流れのように』(1989)、北島三郎『北の大地』(1991)、森進一『酒無情』(1991)、藤あや子『こころ酒』(1992)、香西かおり『無言坂』(1993)、坂本冬美『夜桜お七』(1994)。

### 型E: キャラクター・イラスト型（アニソンの様式）

- 年代・ジャンル適性: アニメ主題歌・キャラクターソング。1989年以降に成立し、1990年代を通じて様式が安定している。アルバム調査の型I（キャラクター・イラスト）と同じ構図。
- 構図: 描き下ろし/原作イラストが全面。キャラクターの全身や顔のアップ、象徴的なモンスターやメカを置き、上部に作品ロゴを固定する。
- タイポグラフィ: 作品ロゴタイプが主役級の記号として働く。曲名と歌手名は中段から下部に併記され、オープニング/エンディング両曲を大きく併記する両A面式も定番。極端な例では表面に曲名も歌手名もない（松本梨香『めざせポケモンマスター』はピカチュウと作品ロゴのみ）。
- 色彩: セル画の原色。作品の映像トーンに従う。
- 帯・クレジットの扱い: 上部や下部の色帯にレーベルロゴ・品番・価格・CD SINGLEロゴを集約する（DALI『ムーンライト伝説』の星柄の白帯＋赤帯など）。
- 画像の題材方向: 主人公と相棒、作品の象徴物（神龍、モンスターボールなど）。
- 注意: アニソンでも歌手の写真を使う盤は多い（馬渡松子『微笑みの爆弾』、BAAD『君が好きだと叫びたい』、田村直美『ゆずれない願い』、FIELD OF VIEW『DAN DAN 心魅かれてく』）。これらはアニメ絵を使っていないため型Eではなく、時代の型（主に型B）に割り当てた。型Eの条件は「アニメの絵が主役であること」。
- 具体例（裏付け12点）: 影山ヒロノブ『CHA-LA HEAD-CHA-LA』(1989)、DALI『ムーンライト伝説』(1992)、高橋洋子『残酷な天使のテーゼ』(1995)、TWO-MIX『JUST COMMUNICATION』(1995)、奥井雅美『輪舞 -revolution』(1997)、松本梨香『めざせポケモンマスター』(1997)、グミ『Catch You Catch Me』(1998)。

### 型F: グラフィック/作字型（全年代のデザイン主役）

- 年代・ジャンル適性: 全年代のポップス/ロックに点在する。デザイナーや作字の作家性が強い盤、顔を出したくないバンドの逃げ道として機能した。アルバム調査の型G（グラフィック/作字）に対応する。
- 構図: 人物のポートレートを使わず、図形・イラスト・コラージュ・オブジェの写真・作字そのものを画面の主役に置く。余白を大きく取る例もある（奥田民生『愛のために』は赤地に小さなイラストのみ）。
- タイポグラフィ: 作字（描き文字・変形レタリング）が核。文字だけの表面（プリンセス・プリンセス『世界でいちばん熱い夏』はクリーム色の地にタイトルと名前と小さいマークのみ）まで含む。
- 色彩: 原色の対比、色面の大きな分割。写真系より色の「面」が強い。
- 帯・クレジットの扱い: クレジット小字は下端に集約されることが多い。
- 画像の題材方向: 抽象図形、イラストレーション、シルエットの反復（スピッツ『チェリー』）、オブジェ（globe『Feel Like dance』の赤い球体）。
- 具体例（裏付け23点）: 爆風スランプ『Runner』(1988)、UNICORN『大迷惑』(1989)、プリンセス・プリンセス『世界でいちばん熱い夏』(1989)、Mr.Children『Tomorrow never knows』(1994)、globe『Feel Like dance』(1995)、スピッツ『チェリー』(1996)、ポルノグラフィティ『アポロ』(1999)。

## 時代を通じた共通項

- **主役は「1枚の強い絵」**。どの型でも判型いっぱいの写真/絵が核で、文字は大きく叫ぶか（型A/B/D）小さく囁くか（型C）の両極に寄る。アルバム調査と同じ傾向が、短冊判型でも確認できた。
- **短冊の判型自体がデザイン要素**。縦組み文字、上下のゾーン分け、写真＋パネルの二段構成が全年代で反復される。横向きに寝かせて使う短冊の写真でも、ゾーン構成の読み取り方は変わらない。
- **表面の情報量は時代とともに減る**。1988–1991年は価格・品番・クレジットまで表面に載る（型A）。1992–1995年は情報の一部がタイアップシールへ分離する（型B）。1996–1999年は情報が裏面へ回り、表面は写真と最小限の文字だけになる（型C）。ただし演歌（型D）だけは最後まで高密度を保つ。
- **「商品としての記号」も時代の記号**。レーベルの帯・価格表記・レンタルシール・タイアップシールは、時代の空気を伝える要素として効く。とくに1990年代中盤以降は、情報の置き場所がジャケット本体からシールへ移る転換が読み取れる。
- **ジャンル様式の独立性**。演歌（型D）とアニソン（型E）は、時代の流行とは別系統で様式が維持される。流行の文法（型A→B→Cの流れ）に乗るのはポップス/ロックの主流だけで、様式の決まったジャンルは独自の型を持ち続ける。
- **写真とイラストの使い分け**。歌手ものは写真が絶対優位。アニソンはイラストが原則。ロックには全年代を通じてグラフィックへの逃げ道（型F）がある。
- **裏面の定型は「写真（絵）の続き＋情報ブロック」**。情報ブロック（品番・価格・バーコード・権利表記・STEREO/発売日）は上部か下部の帯に集約される（前回調査の知見を、今回の展開写真でも複数確認した）。

## デジタルシングルCDでの使い方

- 表絵は、作品の性格に合わせて型を1つ選ぶ。型は年代の再現ではなく「様式の文法」として使う（例: 現在の作品に型Aを使えば、発売当時の商品感の引用になる）。

| 作品の性格 | 向く型 |
|---|---|
| 賑やかでポップ、「商品」らしい発売当時の空気を出したい | 型A 帯＋ポートレート |
| 文字で勝負したい、1990年代前半の勢いと設計感 | 型B タイポグラフィ勝負 |
| 静かで都会的、ファッション写真の空気 | 型C ファッション写真 |
| 演歌・歌謡の情念、叙情 | 型D 演歌・歌謡様式 |
| アニメ/キャラクターの世界観 | 型E キャラクター・イラスト |
| デザイン先行、顔を出したくない、作字で見せたい | 型F グラフィック/作字 |

- **生成で型から決まるパラメータ**（表絵の生成指示にそのまま渡す）:

| 型 | 題材 | 構図 | タイトル配置 | 書体 | 色彩 | 帯・クレジット |
|---|---|---|---|---|---|---|
| A | 歌い手のポートレート | 写真＋色帯/パネルの二段、上端に帯 | 大きく、写真に重ねるか帯の中 | 筆文字/極太ゴシック/スクリプト | レーベル色＋原色の帯 | 表面に小字クレジットを載せる |
| B | 集合写真・顔のアップ・仕掛け写真 | 分割・斜め・色面で挟む | 巨大に、縦積み・斜め・字間の実験 | セリフ/ゴシック太、作字 | 原色対比・色面分割、モノクロ＋金 | 情報はシールへ分離し始める |
| C | ファッション写真・顔のクローズアップ | 全面写真、ミラー/横向き等の写真表現 | 隅に小さく、縦組み・字間広く | 細ローマ字、小文字 | 低彩度・モノクロ・白基調 | 表面に載せない（裏面へ） |
| D | 着物/礼装のポートレート | 人物中央、背景は無地/情景を薄く | 縦書きで大きく | 筆文字/明朝、金・白・赤 | 金・赤・紺の重い色 | 下部に品番・価格・ロゴを集約 |
| E | キャラクターと象徴物 | イラスト全面、上部にロゴの置き場 | ロゴを固定、曲名・歌手名は中〜下部 | 作品ロゴ風のロゴタイプ | セル画の原色 | 色帯にレーベル情報を集約 |
| F | 抽象図形・イラスト・オブジェ | 面の分割、図像中心、余白大も可 | 文字自体が図像 | 作字/変形レタリング | 原色対比・大色面 | 下端に集約 |

- どの型でも、短冊の判型（約1:1.938）いっぱいに絵を使うことと、折り目の演出を入れないことは共通（オーナー指示）。題材はライナーノートの世界観から取る（曲ジャケットの融合や流用はしない）。

### 旧型（2026-11-04調査）から新型への対応

| 旧型 | 新型 | 変更の内容 |
|---|---|---|
| 型A: 1988–1991（黎明期・アイドル/歌謡型） | 型A: 帯＋ポートレート型 | 中核は同じ。定義を「帯/パネル＋ポートレート＋表面クレジット」に精密化した。旧調査で型Aの時代に入れていた非写真の作例（ロゴ・イラスト主役）は型Fへ分離 |
| 型B: 1992–1995（全盛期前半・タイポグラフィ勝負型） | 型B: タイポグラフィ勝負型 | 中核は同じ。ビーイング系の様式を分派として明記し、グラフィック主役の作例は型Fへ分離 |
| 型C: 1996–1999（全盛期後半〜末期・ファッション写真型） | 型C: ファッション写真型 | 中核は同じ。1994年の先行例（L'Arc〜en〜Ciel『Blurry Eyes』）を型Cに割り当てるなど、年代ではなく文法で決めることを明記 |
| （なし） | 型D: 演歌・歌謡様式型 | 新規。前回調査では未収集だった演歌・歌謡14点から起こした |
| （なし） | 型E: キャラクター・イラスト型 | 新規。アニソン16点から起こした（歌手写真のアニソンは型Eに含めない） |
| （なし） | 型F: グラフィック/作字型 | 新規。全年代に点在する非ポートレートの作例23点から起こした |

- **制作実績との対応は変わらない**: NK-S001『チョコミントの残像』=型A、NK-S002『友達のままじゃ』=型C、NK-S003『京葉線の午後』=型B、NK-S004『HAMMOCK AT LOW TIDE』=型B、NK-S009『Flavor』=型C は、新体系でも同じ型である。
